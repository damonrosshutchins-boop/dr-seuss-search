          Account & moderation
          
				
          Current account: Loading…
          
				
				
				Admins see only the active tab's domain, not the full URL, search terms or page contents. You can turn off routine sharing, but blocked-domain safety checks still apply inside this proxy. Admins can open new in-site tabs, which you may close.
				
          
					
					
					Multiple people can use the admin code to become admins at the same time. Each admin keeps their own browser account.
				
          
				
          
				
          
					
          Proxy visitors & restricted accounts
          
					
          Online visitors appear here with their shared active site domain. Private paths, search queries, and page contents are not shown. Restricted accounts remain listed for restoration.
          
					
					
          Use Message for a private popup, or Go to site to open an HTTPS address in a new tab inside that visitor's Seuss Search page. Visitors are notified and can close the tab.

You can block additional domains below; custom rules block and report but do not automatically ban.

          welcome aboard
          
			
          How to use Dr. Seuss Search
          
			
            
				
          1. Search the web: type a search or website address in the big box and press Go.
            2. 
				
          2. Browse: use the toolbar to go back, forward, reload, change the address, or return home.
            3. 
				
          3. Try the VM: open VM to run the included browser-based demo systems and DOS arcade titles on your device.
            4. 
				
          4. Make it yours: open Settings to choose a search engine, background image, accent color, theme, and motion preferences.
            5. 
			
          
			
          Some websites block embedding or require browser features that a web proxy cannot provide. Loading a page inside the proxy does not guarantee that cloud gameplay or streaming will work.
