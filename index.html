          Settings
          
			
			
			Want to use Render directly? Open the public Render-hosted Scramjet website. It runs as a separate site, not a relay for GitHub Pages, and keeps the existing Wisp settings.
			
			Optional for Seuss Browser. DuckDuckGo and other search websites may refuse embedding; browser protections are respected. Custom Loader text searches always open the DuckDuckGo results link.
			
			
			
			
			
			
          
				
				
			
          
			The test checks a Wisp WebSocket handshake, not whether a destination website loads. Press Save to apply your selection. Public relay operators may see traffic metadata, and some relays may reject connections.
			
			
			
          
				
				
			
          
			BareMux remains the underlying transport manager. Scramjet still requires its service worker. Seuss Browser is the existing no-service-worker mode, using ordinary browser embedding without a proxy.
			
          
				
          Admin Relay Session
          
				
				
				This relay preference is never saved to the site's settings. Every activation requires server-verified admin permission; it is cleared when the tab closes or site access changes. The endpoint remains visible to your browser, network, and relay operator. It does not make Custom Loader use Wisp, does not bypass website rules, and does not replace Scramjet's service worker.
				
        The code is checked privately by Render alongside your verified admin account. It is never saved in your browser settings or GitHub. Your normal Wisp stays selected unless you explicitly enable this admin option.

          welcome aboard
          
			
          How to use Dr. Seuss Search
          
			
            
				
          1. Search the web: type a search or website address in the big box and press Go.
            2. 
				
          2. Browse: use the toolbar to go back, forward, reload, change the address, or return home.
            3. 
				
          3. Try the VM: open VM to run the included browser-based demo systems and DOS arcade titles on your device.
            4. 
				
          4. Make it yours: open Settings to choose a search engine, background image, accent color, theme, and motion preferences.
            5. 
			
          
			
          Some websites block embedding or require browser features that a web proxy cannot provide. Loading a page inside the proxy does not guarantee that cloud gameplay or streaming will work.
