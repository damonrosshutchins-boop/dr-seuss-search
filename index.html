          Sign up or log in
          
			
          
				
          Create an account with a username and password. No email is needed. Existing accounts can log in from another device.
          
			
			New usernames must be 3–24 characters: letters, numbers and underscores; begin with a letter.
			
			
          
				
				
			
          
				Passwords are verified by Supabase Auth. Because no email is collected, there is no automatic password-reset email. Keep your password somewhere safe. Older accounts created with an email can still log in using that email in the username field.
			
          
			
          
				
          Choose one way to enter
          
				
          Enter an invitation code and you're in, or request approval from a moderator. You do not need both. A verified moderator code also grants moderator access automatically.
          
				
				
				
          or
          
				
				
          
				
				
			
          
			Site moderation and safety: Current website domains are shared with admins by default; you can switch off routine sharing in Settings. Website safety rules still check domains opened inside Seuss Search, even with sharing off. Blocked visits are reported; visits to recognized adult-content sites can automatically restrict your site account. Admins can review and lift bans. No full URLs, search terms or page contents are recorded.

          welcome aboard
          
			
          How to use Dr. Seuss Search
          
			
            
				
          1. Search the web: type a search or website address in the big box and press Go.
            2. 
				
          2. Browse: use the toolbar to go back, forward, reload, change the address, or return home.
            3. 
				
          3. Try the VM: open VM to run the included browser-based demo systems and DOS arcade titles on your device.
            4. 
				
          4. Make it yours: open Settings to choose a search engine, background image, accent color, theme, and motion preferences.
            5. 
			
          
			
          Some websites block embedding or require browser features that a web proxy cannot provide. Loading a page inside the proxy does not guarantee that cloud gameplay or streaming will work.
